# ⚽ Trybe Futebol Clube  

## 📖 Descrição Breve  

O **Trybe Futebol Clube** é um projeto que simula um campeonato de times de futebol brasileiro, com funcionalidades como:  

- Sistema de pontuação.  
- Manipulação de partidas (finalizar, editar, alterar em andamento).  
- Visualização de partidas em andamento e já finalizadas.  
- Classificação dos times em uma tabela de pontos.  

Este foi o primeiro projeto **FullStack**, onde o backend e o frontend se comunicam, utilizando **TypeScript**, **POO**, e todos os aprendizados dos projetos anteriores.  

## 💻 Como Rodar o Projeto  

1. Clone o repositório:  
   ```bash  
   git clone https://github.com/Gzuuu/trybe-football-club.git  
   ```  
2. Entre na pasta do projeto:  
   ```bash  
   cd trybe-football-club  
   ```  
3. Instale as dependências:  
   ```bash  
   npm install  
   ```  
4. Certifique-se de que o Docker está instalado e execute:  
   ```bash  
   docker-compose up  
   ```  
5. Altere as variáveis de ambiente conforme listado no arquivo `.env-example` (localizado em `app/backend`).  
6. Acesse o projeto no navegador em `http://localhost:3000`.  

## 🛠️ Tecnologias Utilizadas  

- **TypeScript**  
- **Node.js**  
- **Express**  
- **Sequelize**  
- **MySQL**  
- **Docker**  
- **React**  

## 🌟 Funcionalidades  

- **Login** e autenticação de usuários.  
- Sistema completo de **partidas**:  
  - Finalizar, editar, ou alterar partidas em andamento.  
  - Visualizar partidas em andamento ou finalizadas.  
- Tabela de **classificação** com pontuação dos times.  
- Backend e frontend integrados para experiência completa.  

## 🚀 Aprendizados Principais  

- Integração de **backend** e **frontend** em um projeto **FullStack**.  
- Gerenciamento de partidas e tabelas com **POO** e **Sequelize**.  
- Manipulação de variáveis de ambiente para configuração do projeto.  
- Estruturação de aplicações completas com **Docker Compose**.
